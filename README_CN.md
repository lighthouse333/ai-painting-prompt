# AI绘画提示词生成器

基于《女性人物肖像参数化描写模板》的 Claude Code 技能，输入人物特征即可自动生成完整的 28 维度 AI 绘画提示词（.docx 格式）。

## 快速开始

1. 将本仓库克隆到本地
2. 在 Claude Code 中打开项目目录
3. 输入 `/ai-painting-prompt <人物描述>` 即可使用

```
/ai-painting-prompt 生成一个25岁清冷气质的长发女性，穿着简约通勤装，在咖啡馆窗边，秋日午后光线
```

## 工作流程

1. **需求采集** — 从输入中提取年龄、气质、妆容、身材、服装、场景等信息，缺失项主动询问
2. **趋势调研** — 涉及"最新""流行"等关键词时，搜索当前趋势
3. **28维度填充** — 严格按照模板填充每个维度，不跳不漏
4. **生成Word文档** — 使用 python-docx 生成格式化文档
5. **输出摘要** — 展示人物速览表格和文件路径

## 核心原则

- **写实还原** — 以真实女性为描画对象，不过度美化、不网红化、不AI脸
- **28维度全覆盖** — 每个维度必须填充，不可跳漏
- **S/A/B优先级** — 五官脸型(S)、发型肤色身体比例(A)、服装场景(B)
- **禁止清单附带** — 塑料皮、过度磨皮、二次元化、异常人体结构等
- **时效性** — 涉及"最新""流行"等自动搜索当前趋势
